# 简易示波器使用说明

适用于 **德飞莱超翼M35（STM32F103ZET6）+ 2.8" ILI9325 LCD**，三按键 + ADC1/ADC2 双通道同步采样。

---

## 1. 硬件接线

### 信号输入

| 通道 | 引脚 | 说明 |
|------|------|------|
| **CH1** | **PA0**（ADC1_IN0）| 仅接 **0 ~ 3.3V** 信号；高于此范围请加分压电阻 |
| **CH2** | **PA1**（ADC2_IN1）| 仅接 **0 ~ 3.3V** 信号；高于此范围请加分压电阻 |

> ⚠️ PA0/PA1 直接连 ADC，**严禁超过 3.3V 或负压**。建议每路都加保护电路：
> ```
> 信号 → [10kΩ] → PA0/PA1
>                 │
>          [钳位二极管对 0~3.3V]
>                 │
>                GND
> ```

### LCD

板载 TFT 排母直插，FSMC 接口，无需外接线。横屏 320×240 显示。

### 按键（三键方案）

| 按键 | 引脚 | 功能 |
|------|------|------|
| **KEY0** | PE4 | 时基切换（往更慢档跳） |
| **KEY1** | PE3 | 电压量程切换（双通道共用） |
| **KEY2** | PE2 | Run / Stop 切换 |

> WK_UP/PA0 已被 CH1 占用，**不能用作按键**。

### 串口

- 上电时通过 **USART1**（115200 8N1）打印一行 `LCD ID: xxxx`，可在 PC 端确认 LCD 模块识别正常。

---

## 2. 双通道工作原理

- ADC1（CH1）+ ADC2（CH2）配置为 **DUAL REGSIMULT**（双重规则同步）模式
- TIM3_TRGO 同时触发两个 ADC，每个采样点 **CH1 与 CH2 严格在同一时刻取值**——这正是观察互补 PWM、相位关系所需要的
- DMA 走 ADC1 端的 32-bit 字模式，每次搬一个字：低 16 位 = CH1，高 16 位 = CH2
- 屏幕颜色：**CH1 绿色（GREEN）**，**CH2 青色（CYAN）**
- 测量栏（右侧 80px）只显示 CH1 的 Vpp/Max/Min/Avg/Frq，CH2 仅画波形作相位/相对幅值参考
- 触发以 CH1 为基准（量程同步）

## 4. 按键操作

### KEY0 — 切换时基（每格时间）

每按一次往**更慢**方向走一档，到末尾循环回最快。共 9 档：

| 档位 | 每格 | 满屏 10 格 |
|-----:|-----:|-----------:|
| 0 | 500 µs/div | 5 ms |
| 1 | 1 ms/div | 10 ms |
| 2 | 2 ms/div | 20 ms |
| 3 | 5 ms/div | 50 ms（默认） |
| 4 | 10 ms/div | 100 ms |
| 5 | 20 ms/div | 200 ms |
| 6 | 50 ms/div | 500 ms |
| 7 | 100 ms/div | 1 s |
| 8 | 200 ms/div | 2 s |

> F103 单 ADC 上限约 1 MSPS（1µs/点），双重模式下两路同时取样，**每路速率不变**。
> 测 PWM 频率上限：约 50 kHz 看得清；100 kHz+ 波形开始失真。

### KEY1 — 切换电压量程（双通道共用）

每按一次循环到下一档，共 6 档；CH1 和 CH2 共用同一垂直显示比例：

| 档位 | 每格 | 满屏垂直范围 |
|-----:|-----:|------------:|
| 0 | 62.5 mV/div | 0.5 V |
| 1 | 125 mV/div | 1.0 V |
| 2 | 250 mV/div | 2.0 V |
| 3 | 500 mV/div | 4.0 V（默认） |
| 4 | 1 V/div | 8 V |
| 5 | 2 V/div | 16 V |

### KEY2 — Run / Stop

按一次冻结当前波形（状态栏显示 **STP**），再按一次恢复采样（**RUN**）。

## 5. 右侧信息栏

只反映 **CH1**：

| 字段 | 含义 |
|------|------|
| **Vpp** | 一屏 CH1 波形峰峰值（V） |
| **Max** | CH1 最大瞬时电压（V） |
| **Min** | CH1 最小瞬时电压（V） |
| **Avg** | CH1 一屏平均电压（V） |
| **Frq** | CH1 频率估算，以 Avg 为基准计上升过零点；**仅周期性信号 + 至少 2 个完整周期可见时有效** |
| **Trg** | 触发电平（默认 1.65 V，固定不可调） |

> CH2 不参与测量计算；如需 CH2 测量值，可在主循环增加一次 `Osc_Measure` 调用并扩展 `OscState` 字段。

## 6. 测电机互补 PWM 的典型用法

1. **CH1 接上桥 PWM**，**CH2 接下桥互补 PWM**（务必先各自分压到 ≤ 3.3V）
2. 将公共地（PWM 驱动板的 GND / 电机母线 GND）连到示波器板的 GND
3. KEY0 选合适时基：
   - 20 kHz PWM → 50µs 周期 → **20 µs/div** 档（每周期约 2.5 格）
   - 10 kHz PWM → 100µs 周期 → **20 µs/div** 或 **50 µs/div**
4. KEY1 调整量程使两路波形都在屏内
5. 应该看到：CH1 高时 CH2 低，反之亦然；上升下降沿之间存在死区（电平交叠为低）
6. KEY2 暂停冻结，仔细观察死区时长（受限于 1µs 采样间隔，能识别 1~2µs 死区）

---

## 7. 触发说明

- 默认 **AUTO 模式**：无论是否找到触发点都刷新一屏
- 代码层面也实现了 NORM / SING（无 UI 切换入口；改 `g_osc.trig_mode` 初值即可启用）
- 触发以 **CH1** 为基准（电机 PWM 场景下 CH1 选上桥更稳定）
- 触发电平默认 **1.65 V** 上升沿，画面以黄色虚线标示

---

## 8. 上电启动顺序

1. 上电 → 状态栏显示默认值：`5ms/div  500mV  AUTO  /\  RUN`
2. 屏幕中央十字 + 虚线网格出现
3. 右侧信息栏显示初值
4. PA0/PA1 接信号后，CH1（绿）和 CH2（青）波形开始刷新
5. 按 KEY0/KEY1 切换档位，按 KEY2 暂停 / 继续

## 9. 常见问题

| 现象 | 排查 |
|------|------|
| 整屏白色 | UART1 是否输出 `LCD ID: ...`；如未输出说明卡在初始化 |
| 屏幕方向倒了 | `User/main.c` 中 `lcd_display_dir(1)` 后追加 `lcd_scan_dir(R2L_D2U)`（4 个方向常量见 `lcd.h`） |
| CH2 不动 / 一直贴底 | PA1 没接信号；或 PA1 在你的板子上被其他外设占用，检查原理图 |
| 两路波形重叠看不清 | 给两路加不同的直流偏置（CH1 偏置高、CH2 偏置低）让显示分开 |
| 波形溢出 / 削顶 | 输入超出当前量程或 0~3.3V；KEY1 加大量程 |
| 高频 PWM 失真 | 时基太慢；KEY0 切到更快档（最快 500 µs/div = 1 MSPS） |
| Frq 显示 0 Hz | 信号不周期，或一屏内不足 2 个 CH1 周期；切到更快时基 |
| 按键无反应 | 板子上 PE4/PE3/PE2 物理按键是否常开接 GND |

## 10. 性能参数

| 项目 | 值 |
|------|---|
| ADC | STM32F103 内置 12-bit × 2，**ADC1+ADC2 同步规则模式** |
| 通道数 | 2（CH1=PA0，CH2=PA1） |
| 每路最快采样率 | ≈ 1 MSPS（500 µs/div 档） |
| 缓冲深度 | 240 个对齐样本（每点含 CH1+CH2） |
| 显示分辨率 | 320 × 240（横屏） |
| 波形区 | 240 × 224 像素，10×8 格 |
| 时基档位 | 9 档（500 µs/div ~ 200 ms/div） |
| 电压量程 | 6 档（62.5 mV/div ~ 2 V/div，双通道共用） |
| 触发 | 边沿触发，AUTO/NORM/SING（默认 AUTO，CH1 为源） |
