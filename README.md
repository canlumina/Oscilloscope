## 在 Keil MDK 中建立工程

1. 新建工程，芯片选 **STM32F103ZE**
2. 勾选标准外设库：`FSMC`, `GPIO`, `ADC`, `DMA`, `TIM`, `RCC`
3. 将 `User/src/*.c` 全部加入工程
4. Include Path 添加 `User/inc/`
5. **复制字库文件**（见下方说明）
6. 编译，下载

---

## ⚠️ 字库说明（必须）

`font.c` 包含 `asc2_1608` 和 `asc2_1206` 两个字库数组，
数据量较大，请从以下任一来源复制：

- **正点原子 ALIENTEK 例程** → `SYSTEM/usart/font.c`
- **野火 STM32 例程** → 字库相关文件
- **在线获取**: 搜索 "STM32 asc2_1608 font.c"

将 `font.c` 放入 `User/src/` 并加入 Keil 工程即可。

## 接线说明

### LCD（2.8寸 ILI9325）
使用板载 **TFT-LCD排母接口**，与FSMC直接相连，无需额外接线。

确认：
- `RS` → `FSMC_A0` (PF0) ✓
- `CS` → `FSMC_NE4` (PG12) ✓
- `RST` → PC5（可在 `lcd.h` 中修改）

### 信号输入
```
外部信号
   │
  [R1: 10kΩ]           ← 限流保护
   │
  PA0 ─────────────────→ ADC1_CH0
   │
  [R2: 10kΩ] → GND    ← 分压（可选，将信号偏置到1.65V）
   │
  [D1+D2: 钳位二极管]  ← 防超压（强烈建议）
```

> **警告：PA0只能接 0~3.3V 信号！**
> 测量5V信号请先用电阻分压（例：R1=20kΩ, R2=10kΩ）
> 测量交流信号需串联100uF电容 + 1.65V偏置

### 按键
| 按键    | 引脚  | 功能              |
|---------|-------|-------------------|
| KEY0    | PE4   | 时基切换（变慢）    |
| KEY1    | PE3   | 电压量程切换        |
| KEY2    | PE2   | 触发电平 +0.1V     |
| KEY3    | PE5   | 触发电平 -0.1V     |
| KEY4    | PC13  | Run / Stop 切换    |

> PA0已用于ADC输入，所以WK_UP(PA0)不再用作按键。
> KEY3改到PE5，KEY4改到PC13，请确认这两个引脚在你的板子上空闲。

## 性能参数

| 参数          | 值                          |
|---------------|-----------------------------|
| 采样精度       | 12bit (4096级)              |
| 最高采样率     | ~500kSPS (ADC_SampleTime_1Cycles5) |
| 可测最高频率   | ~200kHz（理论）             |
| 输入范围       | 0~3.3V（需加保护电路）       |
| 显示分辨率     | 240×320（ILI9325竖屏）      |
| 波形区域       | 240×240（10列×8行网格）     |
| 时基档位       | 500us/div ~ 200ms/div（9档）|
| 电压量程       | 62.5mV/div ~ 2V/div（6档） |

## 扩展建议

1. **加探头分压**：用10:1探头或外接分压网络，可测量更高电压
2. **双通道**：用ADC1_CH0(PA0) + ADC1_CH1(PA1)，交替采样
3. **FFT频谱**：在测量区加简单FFT，显示频谱图
4. **串口上传**：通过USART1将波形数据发给PC上位机
5. **触摸控制**：如果LCD带触摸，可用触摸屏替代按键调参
